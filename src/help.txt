bmo: a host where agents build desktop apps.

Usage:
  bmo guide            how to build an app: read this first
  bmo new <name>       create an app from the starting point
  bmo check <name>     load the app and draw it once, with no window
  bmo shot <name>      save a screenshot of a fresh hidden copy and print its path
                         --keys "j j ?"    press these keys first
                         --wait <seconds>  give slow work this long, before and after the keys
                         --as <label>      save it as <name>-<label>.png, to keep several
                         --dark | --light  pick the appearance
  bmo dev <name>       open the app in a window that reloads on save
  bmo stop <name>      close that window
  bmo run <name>       run the app in a window until it closes [--watch]
  bmo install <name>   install the app in ~/Applications as bmo.<name>
  bmo reload <name>    check the app, then give its open window the new code
  bmo list             the apps, and which are installed

Apps live in {{apps}}.
BMO_HOME picks another home than ~/.config/bmo.
